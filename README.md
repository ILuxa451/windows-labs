# Windows Server Labs

Практические лабораторные по администрированию Windows Server 2019. Стек: Windows Server 2019, PowerShell, VirtualBox.

## Цель

Систематизировать практические навыки и документировать решения реальных проблем, с которыми сталкиваюсь при настройке.

## Лабораторные

### Lab 01 — PowerShell: Аудит и отчет о состоянии сервера

*   Разработка скрипта `Server-HealthCheck.ps1` для диагностики.
*   Сбор данных:
    *   Список остановленных служб с типом запуска `Automatic`.
    *   Топ-5 процессов по потреблению оперативной памяти (RAM).
    *   Последние 10 критических событий из журнала `System`.
    *   Свободное место на диске `C:`.
*   Генерация красивого HTML-отчета с кастомным CSS (`ConvertTo-Html`).
*   Параметризация скрипта (поддержка удаленных ПК через `-ComputerName`).

**Разобранные проблемы:** [troubleshooting](./Lab-01-PowerShell-HealthCheck/)

*   Ошибка `Access Denied` при попытке управлять службами без прав Администратора.
*   Сложности с вычислением свободного места на диске (решено через `Get-WmiObject` и деление на 1GB).

### Lab 02 — Active Directory: Развертывание домена

*   Установка роли `AD-Domain-Services` и создание нового леса `lab.local`.
*   Настройка DNS-сервера на контроллере домена.
*   Переименование сервера в `DC01` согласно стандартам инфраструктуры.
*   Создание иерархии подразделений (OU): разделение пользователей и компьютеров.
*   Создание учетных записей, групп безопасности и настройка членства.
*   Присоединение клиента Windows 11 к домену и проверка аутентификации.

**Разобранные проблемы:** [troubleshooting](./Lab-02-Active-Directory/)

*   Настройка DNS для корректного поиска контроллера домена клиентом.
*   Разрешение доступа к административным сетевым ресурсам (`NETLOGON`, `SYSVOL`).

### [Lab 03 — Построение структуры AD и GPO](./Lab-03-AD-Structure/)

*   Создание сложной иерархии OU (`_Компания` -> `IT_Департамент` -> отделы и группы).
*   Создание пользователей с требованием смены пароля при первом входе.
*   Настройка групп безопасности по модели **AGDLP** (глобальные и доменные локальные).
*   Настройка **Group Policy (GPO)**:
    *   Единая политика длины пароля для домена.
    *   Запрет `cmd` и `regedit` для стажеров.
    *   Включение аудита входа в систему для серверов.

**Разобранные проблемы:** [troubleshooting](./Lab-03-AD-Structure/)

*   Разница между глобальными и локальными группами при настройке прав.
*   Диагностика применения GPO через `gpresult /h` и `gpupdate /force`.

### [Lab 04 — DNS: Исследование и настройка](./Lab-04-DNS/)

*   Изучение структуры AD-интегрированной зоны `lab.local` и служебных SRV-записей.
*   Создание стандартной (файловой) зоны `projectX.internal`.
*   Настройка основных типов записей: A, CNAME, MX.
*   Применение базовых мер безопасности: ограничение трансферов зоны, настройка форвардеров, фильтрация DNS-трафика на брандмауэре.

**Разобранные проблемы:** [troubleshooting](./Lab-04-DNS/)

*   Понимание разницы между прямой и обратной зоной.
*   Использование `nslookup` в интерактивном режиме для проверки записей.

### [Lab 05 — DHCP: Развертывание и отказоустойчивость](./Lab-05-DHCP/)

*   Установка, авторизация и создание области DHCP (пул адресов, параметры шлюза и DNS).
*   Интеграция с DNS (динамическое обновление записей) и создание резервирований по MAC.
*   Настройка DHCP Failover (отказоустойчивость) между двумя серверами в режиме балансировки.
*   Создание политик (Policies) для гостевых устройств и VoIP-телефонов.
*   Управление и мониторинг через PowerShell.

**Разобранные проблемы:** [troubleshooting](./Lab-05-DHCP/)

*   Визуальный баг оснастки `dhcpmgmt.msc` (красная стрелка при рабочем сервере), решено проверкой через PowerShell (`Add-DhcpServerInDC`).
*   Конфликт IP-адресов при клонировании виртуалки (сброс старого IP через `Remove-NetIPAddress`).
*   Ограничение диапазона политики (диапазон политики обязан находиться внутри основного пула).

## Использование

Репозиторий носит учебный характер. Все конфиги обезличены, приватные ключи и пароли не хранятся.
